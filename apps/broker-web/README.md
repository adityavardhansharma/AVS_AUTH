# Broker Web

This app will host the production broker UI for:

- home
- sign-in
- consent
- profile
- authorized sites
- no-session
- error
- legal pages

The current Worker service only exposes placeholder HTML. This app is the required parity surface for release and must implement the UX flows defined in:
