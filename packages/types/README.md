# @avs-auth/types

Shared protocol, claims, and SDK types for AVS AUTH.

## Exports

- Protocol requests and responses: `AuthorizeRequest`, `TokenRequest`, `TokenResponse`, `SessionCheckResponse`
- Identity claims: `IdentityClaims`
- Browser SDK contracts: `AvsAuthOptions`, `PkceBundle`, `AvsIdentity`, `SessionMonitorOptions`
- React SDK contracts: `UseAvsAuthOptions`, `UseAvsAuthResult`
